# Python Examples: Zero to Advanced

These small examples build skills in order. Each folder has a runnable script and notes about the concept it demonstrates. They use Python's standard library and fictional sample data.

| Level | Example | Main concepts |
|---|---|---|
| Zero | [Profile basics](zero/profile_basics.py) | Values, names, strings, output |
| Beginner | [Grade calculator](beginner/grade_calculator.py) | Functions, conditions, validation |
| Intermediate | [Student records](intermediate/student_records.py) | Collections, aggregation, JSON |
| Advanced | [SQLite task query](advanced/sqlite_tasks.py) | Tables, parameterized SQL, filtering |
| Capstone | [Local retrieval](capstone/local_retrieval.py) and [vibe-coding review](capstone/vibe_coding_workflow.py) | Evidence search, citations, allowlists, human review |

Run an example from its folder with `python <filename>.py`. The capstone is deterministic retrieval, not a live AI model call. No example accesses a network or real account.

For larger step-by-step applications, see the [zero-to-advanced project ladder](../projects/learning-ladder/README.md).
