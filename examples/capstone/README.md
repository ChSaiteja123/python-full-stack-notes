# Capstone: Local Retrieval and Vibe Coding

Practice deterministic keyword retrieval, source references, a fixed tool allowlist, and a human-reviewed AI coding workflow.

Run:

```powershell
python local_retrieval.py
python vibe_coding_workflow.py
```

`local_retrieval.py` is a local learning simulation. `vibe_coding_workflow.py` demonstrates that an AI-generated draft stays on hold until acceptance criteria, tests, diff review, and security review are complete. Neither script calls an LLM, executes tools, or sends data anywhere.
